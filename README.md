### What I learned

En este proyecto construí una tarjeta de producto responsive con React y CSS.

Organicé el contenido con HTML semántico: main para el contenido principal, article para la ficha del producto, figure para las imágenes y header para la información introductoria.

Separé la información del producto en bloques: descripción, precios y acción de compra.

Utilicé del para indicar que el precio anterior ya no está vigente.

Importé imágenes y recursos desde assets para poder utilizarlos correctamente en React.

Implementé diseño responsive con media queries: en móvil se muestra una imagen y en tablet se muestra otra, ocultando la que no corresponde con display.

Cambié la distribución de la tarjeta de columna a fila mediante Flexbox según el ancho de pantalla.

Aprendí que flex-grow reparte únicamente el espacio sobrante; no garantiza que dos elementos tengan exactamente el mismo ancho si sus contenidos, imágenes o rellenos son distintos.

Apliqué el color de fondo general al body y el fondo de la tarjeta al article.

Usé transition para suavizar cambios visuales, como los estados hover de un botón.
